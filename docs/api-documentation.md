# API Documentation

Base URL (local): `http://localhost:8000`

All responses are JSON. Interactive docs are also auto-generated by FastAPI at `/docs` (Swagger UI) and `/redoc`.

---

## Health

### `GET /health`
Basic liveness check.

**Response `200`**
```json
{ "status": "ok" }
```

---

## Submissions

### `POST /submissions/`
Submit a new project for evaluation. Triggers the full sandbox pipeline.

**Query/Body Parameters**
| Field | Type | Description |
|---|---|---|
| `student_name` | string | Name of the submitting student |
| `project_name` | string | Name of the project |
| `language_stack` | string | One of: `python`, `node`, `laravel`, `flutter` |
| `submission_type` | string | One of: `github`, `gitlab`, `zip`, `docker_image` |
| `source_url` | string | Repository URL (or file path for ZIP) |

**Response `200`**
```json
{
  "id": "b3f1c2a0-...",
  "status": "pending"
}
```

---

### `GET /submissions/{submission_id}/status`
Check the current pipeline stage of a submission.

**Response `200`**
```json
{
  "id": "b3f1c2a0-...",
  "status": "evaluating"
}
```
Possible `status` values: `pending`, `cloning`, `building`, `running`, `testing`, `evaluating`, `completed`, `failed`

**Response `404`** — submission not found

---

### `GET /submissions/`
List all submissions.

**Response `200`** — array of submission objects

## Evaluations

### `GET /evaluations/{submission_id}/report`
Get the full evaluation report: scores + AI feedback + plagiarism result.

**Response `200`**
```json
{
  "scores": {
    "feature_completion": 100.0,
    "code_quality": 100.0,
    "architecture": 100.0,
    "security": 100.0,
    "api_quality": 100.0,
    "deployment_readiness": 100.0,
    "engineering_maturity": 100.0,
    "overall": 100.0
  },
  "feedback": {
    "strengths": "...",
    "weaknesses": "...",
    "missing_requirements": "...",
    "security_risks": "...",
    "performance_suggestions": "...",
    "refactoring_suggestions": "...",
    "improvement_roadmap": "..."
  },
  "plagiarism": {
    "score": "0%",
    "matches": "none"
  }
}
```

**Response `404`** — report not found (evaluation not completed yet)

## Leaderboard

### `GET /leaderboard/`
Returns top 50 submissions ordered by overall score (descending).

**Response `200`**
```json
[
  {
    "id": "...",
    "submission_id": "...",
    "student_name": "Ali Raza",
    "project_name": "Inventory API",
    "overall_score": 92.5,
    "build_time_seconds": 14.2,
    "architecture_score": 100.0,
    "api_quality_score": 100.0
  }
]
```

---

## Plagiarism

### `GET /plagiarism/{submission_id}`
Returns the plagiarism check result for a specific submission.

**Response `200`**
```json
{
  "plagiarism_score": "0%",
  "matches": "none"
}
```

**Response `404`** — no evaluation found for this submission

---

## Error Format
All error responses follow FastAPI's default shape:
```json
{ "detail": "Submission not found" }
```
